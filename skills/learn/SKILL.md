# /learn — 검증된 교훈 정리

저장 기준과 승인 경계는 프로젝트 AGENTS.md §2.8 및 §2.2가 원본이다.

1. 요청된 회고 범위(미지정 시 현재 작업)의 해결 과정에서 재사용할 수 있는 후보를 찾는다.
2. 기존 docs·교훈과 대조한다. 메모리 도구가 없으면 접근 가능한 문서로 검토하고 저장하지 못한 사실만 보고한다.
3. 새롭고 검증된 후보만 저장한다. name, trigger, 검증된 steps, failureModes를 간결하게 쓰고 메인 저장소 경로·현재 에이전트 식별자를 사용한다.
4. 중복 검색은 반복 적용의 증거가 아니다. 실제 적용 사례가 반복되어 안정화된 후보만 규칙 또는 스킬 승격을 제안한다.
5. 승격은 대상 파일·구체적인 diff·적용 범위·재검토 조건을 준비한 뒤 승인받는다. 이미 해당 승격을 승인받았다면 재질문하지 않는다.
6. 저장·미저장 결과와 필요한 승인만 보고한다. 후보가 없으면 없다고 마친다. 교훈을 만들기 위해 새 작업을 시작하지 않는다.
