# /handoff — 재개 가능한 상태 기록

프로젝트의 AGENTS.md §2.5~2.6, §4를 따른다.

1. git status와 diff로 본인 변경과 사용자 변경, 완료·미완료 작업을 확인한다.
2. 진행 중인 기능의 context/tasks를 동기화한다. 기능 문서가 없는 작은 작업은 간결한 인수인계 보고로 충분하다.
3. context에 실제 상태·오늘 날짜·검증 결과·남은 승인·다음 시작 파일을 기록한다. 미해결 제약과 판단 이유를 우선하며 일시적인 환경 오류를 영구 제약으로 남기지 않는다.
4. 커밋 조건을 충족하면 관련 코드와 문서를 함께 논리적 단위로 커밋한다. 커밋하지 못한 변경은 작업 트리에 보존하고 위치를 기록한다. 자동 stash·reset은 하지 않는다.
5. 메모리가 사용 가능하고 재개 지점이 있으면 체크포인트를 남긴다. 교훈은 AGENTS.md §2.8의 저장 기준을 충족할 때만 저장한다. 도구 실패로 인수인계를 중단하지 않는다.
6. 기능 전체가 완료되었으면 AGENTS.md §2.3의 문서 승격·아카이빙을 수행한다. 장기 결정이 없으면 ADR을 만들지 않는다.
7. 완료·남은 작업·다음 시작점을 보고한다. 사용자가 종료를 요청했으면 인수인계를 마친다. 상태 동기화만 수행했고 요청 범위에 다음 Phase가 남아 있으면 공통 정책에 따라 계속한다.

이 스킬 실행은 작업 완료나 세션 종료의 증거가 아니다. 실제 검증과 사용자 요청으로 상태를 판단한다.
