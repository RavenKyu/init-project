## 접근 방식

선택한 접근을 2~4문장으로. 검토했으나 기각한 대안이 있으면 한 줄씩 명시.

## 단계 (Phases)

작업 크기에 맞는 단계로 분리하고 각 단계에 검증 가능한 결과를 둔다. Phase 경계는 결과 보고 지점이며, 승인 필요 여부는 AGENTS.md §2.2로 판단한다.

- [ ] **Phase 1: [이름]** → 검증: [무엇이 통과하면 완료인가 — 구체적 테스트/명령어]
- [ ] **Phase 2: [이름]** → 검증: [...]
- [ ] **Phase 3: [이름]** → 검증: [...]
