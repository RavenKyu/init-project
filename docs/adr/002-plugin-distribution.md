# 002. 스타터 배포 모델: Claude Code 플러그인 마켓플레이스

- 날짜: 2026-10-09
- 상태: 승인됨 (2026-10-09, ADR-001을 대체)
- 관련 기능: specs/plugin-distribution/

## Context

ADR-001의 서브모듈+bootstrap 방식은 소비 프로젝트에 `.gitmodules`, 심링크, `.claude/settings.json` 훅 등록, `.gitignore` 수정을 커밋하게 만든다. 도입에 서브모듈 학습과 bootstrap 실행이 필요하고, 저장소에 흔적을 남기지 않고 개인 로컬에서만 쓰려는 사용자를 지원하지 못한다.
ADR-001이 플러그인을 보류한 이유는 다른 에이전트가 AGENTS.md를 공유받지 못한다는 점이었다. 2026-10-09에 사용자가 Claude Code 전용 지원으로 결정해 이 이유가 해소됐다. 이는 ADR-001의 재검토 조건("Claude Code 단일 에이전트로 수렴하고 플러그인 마켓플레이스를 운영하게 될 때")에 해당한다.

## Decision

Claude Code 플러그인으로 배포하고, 이 저장소를 마켓플레이스로 운영한다.

- 스킬은 플러그인 스킬(`/init-project:<name>`), 훅은 플러그인 `hooks/hooks.json`으로 제공한다. 문서 양식은 스킬과 함께 번들한다.
- 플러그인 루트의 CLAUDE.md는 로드되지 않으므로, 공통 정책은 SessionStart 훅이 `additionalContext`로 주입한다. 주입은 도입 표식이 있는 프로젝트에서만 한다.
- 프로젝트 상태 문서(docs, specs)는 `/init-project:setup` 스킬이 생성한다. 팀 모드는 커밋 대상으로, 로컬 모드는 `.git/info/exclude`에 등록한다.
- 팀 공유는 `--scope project`, 개인 로컬은 `--scope local`로 설치한다.
- 플러그인 경로(저장소 루트 `"."` 또는 하위 디렉터리)는 `claude plugin validate` 결과로 plan에서 확정한다.
- 서브모듈+bootstrap은 기존 소비 프로젝트의 전환 기간 동안만 유지하고 이후 제거한다. 도입 표식은 `specs/.init-project`, 팀 버전 고정은 마켓플레이스 태그 ref로 한다.

## Alternatives

- 서브모듈+bootstrap 유지 (ADR-001) — 기각: 로컬 전용 사용 불가, 도입 절차 부담.
- 서브모듈과 플러그인 장기 병행 — 기각: 훅 경로·스킬 이름·양식 위치를 이중 관리하고 테스트 범위가 두 배가 된다.
- 정책을 스킬로만 제공 — 기각: 스킬은 호출할 때만 로드되어 항상 적용되는 정책을 보장하지 못한다.
- `CLAUDE.local.md`에서 플러그인 경로를 `@import` — 기각: 플러그인 경로가 업데이트마다 바뀌고, CLAUDE.local.md가 있으면 AGENTS.md를 읽지 않는 동작과 충돌할 수 있다.
- 사용자 범위 설치 후 모든 프로젝트에 정책 주입 — 기각: 도입하지 않은 프로젝트에 정책이 적용된다.

## Consequences

- 좋아지는 것: 도입이 명령 두 개로 끝난다. 로컬 모드에서는 저장소에 아무것도 커밋되지 않는다. 훅·스킬 업데이트가 플러그인 업데이트로 전파된다.
- 감수하는 것 (트레이드오프): Claude Code 전용이 된다. 정책이 CLAUDE.md가 아니라 훅 주입에 의존하므로 10,000자 한도(현재 6,899자)가 정책 크기의 상한이 된다. 스킬 이름이 `/init-project:` 접두사로 바뀐다. 팀원은 폴더를 신뢰한 뒤 각자 설치해야 한다. 버전 고정이 서브모듈 커밋에서 마켓플레이스 ref로 바뀐다.
- 되돌리려면: ADR-001 방식은 git 이력에 남아 있다. bootstrap을 복원하고 플러그인 매니페스트를 제거한다. 소비 프로젝트의 docs·specs는 두 방식에서 같은 위치이므로 손실이 없다.
- **재검토 조건**: Codex 등 다른 에이전트 지원이 다시 필요해질 때 / 정책이 주입 한도의 80%(8,000자)를 넘을 때 / Claude Code가 플러그인의 지침 파일 로드를 지원하게 될 때 / 훅 주입 정책이 CLAUDE.md 대비 준수율이 낮다는 근거가 나올 때.
